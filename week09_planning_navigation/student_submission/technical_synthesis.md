A suitable route for a robot should get it to the goal without hitting obstacles or getting too close to people and it's a bonus if it's also the shortest path available. After testing different planners across the three missions, I learned that a shorter path doesn't always mean it's the safest. In mission 2 we saw that a planner might perform well on an open map but struggle with narrow passages and more obstacles. In mission 3 increasing repulsion strength did not always improve the path because some conditions caused the planner to get stuck or fail. Also, since these tests were done in simulation, the results are only estimates so a real robot might perform differently in an actual environment where people and obstacles can move. Overall, the robot needs to balance finding an efficient path with avoiding obstacles and keeping a safe distance from people.
