## Response

I also learned that even though AI can be helpful when implementing the functions a robot needs, it does not automatically give the correct answer. We still need to review and verify the code before testing and running it because there can be mistakes or test cases that we may not think about. I also learned that technical work needs to consider the environment around the robot. A robot may be able to move from one position to another correctly, but it also needs to be aware of its surroundings and stay within a safe area when operating around people or objects. What stood out to me the most was how important it is to be careful when using AI tools. I should not just trust the output because it looks correct. I need to understand what the code is doing, check it against the requirements, test it, and make changes when needed. This activity showed me that AI can be useful for robotics, but the person using it is still responsible for making sure the final result is correct and safe.
